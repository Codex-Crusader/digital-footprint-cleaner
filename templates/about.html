Why it exists

Searching your own name is the obvious way to check your exposure, and it is a bad one. A single query returns one ranking algorithm's ten best guesses, and it systematically misses the pages that matter most: people-search and directory listings rank poorly for bare names, so the sites publishing your address and phone number are exactly the ones a casual search never shows you.

This tool runs several narrow searches instead of one broad one, then judges which results are actually you rather than a namesake, and gives you the verified opt-out link for each listing it finds.

How it works

Deep search
A scan is a plan of separate searches (name variants, site-scoped platform checks, public-record sweeps) run under one time budget through a shared rate governor that backs off when the search provider throttles it.
Narrowing
Employer, age, relatives and the rest are never added to the query; extra search terms find fewer pages, not more. They are scored against the results instead, so namesakes sink and real matches rise.
Honest gaps
A check that failed is reported as failed, never as "nothing found". Telling someone they are clean when nobody managed to look is the worst thing a tool like this can do.
Storage
Scan results live in memory for 30 minutes and never touch disk. The removal tracker is a local SQLite file you can wipe in one click.
No JavaScript
The whole interface is HTML and CSS under a strict Content-Security-Policy. Nothing here executes a script.
